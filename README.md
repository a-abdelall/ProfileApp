# Flutter Profile Screen

A modern and responsive Profile Screen built with Flutter, showcasing a clean and professional user interface for displaying profile information.

## Features

* Modern and clean UI design
* Responsive layout
* Profile avatar section
* Organized information cards
* Additional information section
* Bio/About section
* Material 3 design
* Clean and maintainable code structure
* Flutter widgets only
* No backend or API integration

## Technologies Used

* Flutter
* Dart
* Material 3

## Project Structure

```text
lib/
└── main.dart
```

## Getting Started

### Prerequisites

* Flutter SDK
* Dart SDK
* Android Studio / VS Code
* Android Emulator or Physical Device

### Installation

1. Clone the repository

```bash
git clone <repository-url>
```

2. Navigate to the project folder

```bash
cd profile-screen
```

3. Install dependencies

```bash
flutter pub get
```

4. Run the application

```bash
flutter run
```
